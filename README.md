# DEAD SIGNAL — 마지막 무전 3.0

Windows용 1인칭 3D 좀비 생존 게임입니다.

## 전투 개편

- Blender에서 제작한 좀비 3종과 관절 애니메이션
- 추격, 러너 돌진, 할퀴기 전조, 피격 경직, 쓰러짐
- F 밀쳐내기, 다리 명중 시 이동 저하, 헤드샷, 폭발 연료통
- 연속 처치 점수와 시설 방어전, 순차 해금되는 7개 작전
- Blender 총기 3종: 카빈, 샷건, 기관단총

외형은 스타일화된 인디 3D입니다. 실사 그래픽은 아닙니다.

## 조작

WASD 이동 · 마우스 시점 · 좌클릭 사격 · 우클릭 정조준

F 밀쳐내기 · R 재장전 · Shift 달리기 · Space 점프 · Ctrl 회피 · Q 수류탄

E 유지 상호작용 · B 응급 치료 · Esc 일시정지 · F11 전체 화면

## 배포 상태

Windows 실행 폴더와 전체 소스 ZIP은 로컬에서 생성했고 CRC와 SHA-256 검사를 마쳤습니다. 현재 브라우저의 로컬 파일 접근 설정 때문에 GitHub 파일 업로드는 대기 중입니다.

## 검증

자동 검사 30개 통과. 실제 Windows 실행 파일의 WebGL 초기화, 좀비 GLB 3종 로드, 첫 작전 전투 화면과 공격에 따른 체력 감소를 확인했습니다. 사람의 조작으로 전체 캠페인을 완주한 결과는 아닙니다.
